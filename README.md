# PixelLab 像素暗房

一个纯前端的图像像素化处理工具，无需安装、无需服务器，下载 HTML 文件用浏览器打开即可使用。

## 功能概览

### 导入图像
- 拖拽图片文件到页面任意位置
- 点击左侧导入区域选择本地文件
- 支持 PNG、JPG、WebP、GIF 等浏览器原生支持的格式

### 裁剪与调整尺寸
- 输入目标宽度和高度（单位：像素）
- 比例预设：自由 / 1:1 / 4:3 / 16:9 / 3:2 / 2:3
- 选择比例后锁定长宽比，修改一边自动计算另一边
- 裁剪方式为居中裁取后缩放至目标分辨率

### 处理模式

#### 原图
不做任何处理，可直接用于格式转换或尺寸调整。

#### 纯黑白
基于亮度的二值化处理。
- **阈值**（0–255）：高于阈值的像素变为白色，低于的变为黑色
- **对比度**（-100–100）：二值化前预调整图像对比度

#### 抖动明度
用黑白像素的疏密分布模拟连续灰阶，四种算法可选：

| 算法 | 特点 |
|------|------|
| Floyd-Steinberg | 误差向右下方扩散，过渡自然，边缘清晰 |
| Atkinson | Apple Macintosh 经典算法，高光保留更好，整体偏亮 |
| 有序抖动 (Bayer) | 基于 8×8 Bayer 矩阵，产生规则的网格图案 |
| 随机抖动 | 加入随机噪声，颗粒感强，风格粗粝 |

参数：
- **阈值**：控制明暗分界点
- **噪点强度**：叠加随机扰动量，对有序抖动可控制 Bayer 图案的对比幅度

#### 色阶像素
将图像按亮度量化为 N 个色阶，每个像素块用固定几何形状填充，模拟网版印刷或像素艺术风格。

参数：
- **色阶数**（2–16）：亮度分级数量，数值越小色调越硬
- **像素块大小**（2–32px）：每个采样块的边长
- **排列图案**：方块 / 圆形 / 横线 / 十字 / 菱形
- **保留色彩**：勾选后以原始色彩填充图案，取消则为灰度

### 右侧信息面板

- **信息**：原始尺寸、输出尺寸、处理模式、文件名
- **直方图**：当前图像的亮度分布
- **调色板**：K-Means 算法提取的 8 个主色，点击色块可复制 HEX 值

### 导出
- **导出 PNG**：无损格式，适合像素艺术和有透明需求的图像
- **导出 JPG**：92% 质量，文件体积更小
- 文件名自动附加 `_pixellab` 后缀

## 技术实现

- 纯原生 HTML / CSS / JavaScript，零依赖，零构建步骤
- 所有图像处理通过 Canvas 2D API 在本地完成，不上传任何数据
- 抖动算法在 `Float32Array` 上操作以保留误差精度
- 调色板提取使用 K-Means 聚类（k=8，迭代 10 次）
- 有序抖动采用标准 8×8 Bayer 矩阵（64 阶）
